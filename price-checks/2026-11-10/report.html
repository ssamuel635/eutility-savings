How this report guards against wrong numbers
  • Official sources only. Every number links to the retailer’s own page or fact sheet. Comparison sites are never used as a source.
  • No guessing. If a page can’t be read, the plan is marked “couldn’t verify” and keeps its current price. Nothing is filled in.
  • Quote check. The agent copies the exact text it read; the script rejects any number that isn’t in that text.
  • Sanity checks. Rates outside 15–45¢, jumps over 15% in a week, oversized discounts, and with-GST / without-GST pairs that don’t match (×1.09) are blocked.
  • Second read. Anything that would change the top 3 recommendations or move a typical bill by S$5+/month must be read a second time by a separate pass (different method, e.g. the retailer’s fact sheet or data feed). If the two reads disagree, it’s blocked.
  • Contract terms too. Each plan’s deposit and early termination fee are read from its fact sheet. A change needs the numbers in the new wording to appear in the fact sheet text, and a second read that finds the same numbers.
  • Gaps are tracked. Each unverified plan shows when it was last confirmed; after 21 days it’s marked stale so it gets checked by hand or hidden.
  • A person approves. Nothing reaches the website until someone ticks it here. Blocked items can’t be ticked.
